# Mod Launcher

One app to install and play my game mods (ULTRAKILL, Among Us, Undertale, Minecraft, ROUNDS, How to Fish and more).

## Get it
1. Download **[ModLauncher.zip](https://github.com/cgtsonic2012/mod-launcher/releases/download/packages/ModLauncher.zip)**
2. Right-click it > Extract All, then open `ModLauncher.exe`.
   If Windows says "Windows protected your PC": More info > Run anyway.
3. Pick a mod, press **INSTALL**, then **PLAY**.

The launcher checks this page when it starts, so new mods and updates show up by themselves.

Unofficial fan mods made with Claude Code (AI-assisted). No game files are included; game names belong to their owners.
